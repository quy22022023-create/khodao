CHỈ LÀM MỘT LẦN CHO MỖI DỰ ÁN

Cài đặt trong Supabase

  1. Mở Supabase Dashboard ↗ → chọn dự án. Bảo đảm Data API và đăng nhập Email/Password được bật.
  2. Vào Authentication → Users → Add user, tạo user bằng email/mật khẩu và xác nhận email (Auto Confirm). Sao chép UUID của user đó. Không dùng UUID dự án.
  3. Dán UUID bên dưới. Bấm Sao chép SQL cài đặt, vào SQL Editor của đúng dự án, dán rồi Run. SQL chỉ cấp quyền cho UUID này.
  4. Lấy Project URL và publishable/anon key trong Project Settings. Quay lại đây bấm Đăng nhập với email/mật khẩu vừa tạo.
